# Grand Theft Raki: Новосибирск 🦀

Браузерная 3D-игра-шутка для одного дружеского чата. Вечер 18 ноября 2026, заснеженный Новосибирск, до релиза «той самой игры» пять с половиной минут.

- Играть: https://neol888.github.io/grand-theft-raki/
- Десять поручений от раков чата; в каждой партии выпадает шесть (те, что реже попадались на этом устройстве), своё поручение рак не получает.
- Оригинальная пародия. Не связана с Rockstar Games и Take-Two и не использует их материалы.
- Вся графика, модели, звук и музыка процедурные (геометрия в коде, шейдеры, WebAudio). Three.js (MIT) вшит в `game.js`, внешних запросов во время игры нет.
- Единственный внешний запрос — на финальном экране: результат (рак и очки, без имён) уходит в общую таблицу рекордов на Supabase, оттуда же читается топ. Если сеть недоступна, таблица просто не показывается.

## Сборка

```
npm install
npm run build   # src/ -> game.js
npm run dev     # локальный сервер на :5173
```
